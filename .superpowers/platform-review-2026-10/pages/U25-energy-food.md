# U25-energy-food review

Pages: `/explorer/energy-food/{energy-supply,electricity,energy-use,food-self-sufficiency}`, ka and `/en`. All 8 return 200 on http://localhost:3100.

## Summary
Solid unit that reuses the shared explorer parts; the one real gap is that the phone legend and "back to chart" pill (owner decision D4) were never wired in, so multi-line charts on a phone have no labels at all.
Scores (1-10): code quality 7, performance 8, UI/UX 6, mobile 5, accessibility 6, bilingual 9, SEO 8, security 9, tests 7.
Counts: critical 0, high 1, medium 2, low 7. Browser spec (15 tests, 13.4 s) and both unit files (50 tests, 1.9 s) pass; `git status` stayed clean.
