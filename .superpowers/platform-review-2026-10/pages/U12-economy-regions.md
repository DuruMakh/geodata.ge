# U12-economy-regions review (`/explorer/economy/regions`, `/explorer/economy/regions/[id]`, 11 regions, ka + en)

## Summary
The unit is in good shape. It has no overflow at 375px or 1280px, the ka and en message keys match exactly, and SEO is complete. All 16 browser tests and 12 unit tests I ran pass. The weak points are two sets of hardcoded coverage numbers and dates, copy-pasted region-heading code across four pages, one dead component, and a heavy first-load prefetch from the shared sidebar.
Scores (1-10): code quality 6, performance 6, UI/UX 8, mobile 8, accessibility 7, bilingual 8, SEO 9, security 9, tests 7.
Counts: 0 critical, 0 high, 4 medium, 10 low.

## Checks with no findings
- **Overflow and heading structure:** there is no horizontal overflow at 375px or 1280px on the index, Imereti, Tbilisi (smallest) or Racha-Lechkhumi (longest name, largest-label case), in ka and en. Headings are H1 then H2 only. The H1 contains the picker button; its accessible name has a double space ("—  იმერეთი"), which is cosmetic.
- **Tap targets at 375px:** mode and measure tabs are 36px, range chips 31-40px x 38px, series rows 33px, and the region list rows 43px. The Tbilisi map link is 16x13px, but the coarse-pointer touch disk and preview strip (DESIGN.md §26) cover it. All pass WCAG 2.2 at 24px, and none match the stricter 44px for controls. DESIGN.md §12 says controls should be at least 30px tall, which they meet.
- **Hash state:** `#sel=` is filtered against valid ids, `bogus<img>` is dropped, and the hash is URL-encoded when written back. No `dangerouslySetInnerHTML` is used apart from the JSON-LD helper. The only external link is geoBoundaries with `target="_blank" rel="noreferrer"`. The RSC payload contains only `region.*` and `sector.*` ids and public download paths.
- **SEO:** the title, description, canonical, hreflang (ka, en, x-default), og and twitter tags are correct on both languages. All 11 slugs x 2 languages are in the sitemap, and an unknown slug returns 404. A trailing slash redirects with 308.
- **Bilingual:** the 46 message keys in `regional-economies.json` match between ka and en. The en table and series labels are English, and the controls are identical.
- **Keyboard:** the map uses a roving tabindex with arrow, Home and End keys. A focused map link gets a 2px accent outline, and a focused row gets a 2px ink outline.
- **Design rules:** the measure control is `₾` plus Lucide `ChartPie`, as DESIGN.md §26 requires. The only functional icon used in the unit is the Lucide `ChevronDown` in the picker trigger.

## Missing tests (important behaviour with no unit or browser test)
- The touch preview on the economy index is covered, but the neighbour links (`regional-entity-navigation`) are only checked for visibility. There is no assertion on the previous/next ring wrap (Tbilisi to Shida Kartli, and the reverse) or the 44px target below 768px that DESIGN.md §26 requires.
- The picker: there is no test for Escape returning focus to the trigger, for the Tab behaviour, for `aria-activedescendant`, or for the empty-search state.
- There is no regression test that the page-level metadata (title, description, canonical, hreflang) for a detail page is derived from loaded years rather than hardcoded text. See U12-economy-regions-05.
- A chart text alternative for the economy detail chart is not asserted.
- The detail-page Dataset JSON-LD keys are not asserted beyond the testid count.
