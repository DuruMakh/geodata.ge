# U26-demography-population review

Pages reviewed (live build, localhost:3100): `/explorer/demography/population` (index), `/population/georgia`, `/population/region/imereti` (representative and largest page: 386 KB raw HTML), `/population/lentekhi` (smallest municipality, 5,056 people; Oni was also fetched), `/population/oni`, `/population/batumi`, `/population/region/tbilisi`, `/population/region/kvemo_kartli`, plus `/en/...` twins of all of them. Checked at 375px and 1280px with Playwright. Unit tests were run for 7 files and the browser spec `demography-population.spec.ts` once. `git status` was clean afterwards, so no tracked files needed restoring.

## Summary
Code 6, Performance 7, UI/UX 7, Mobile 8, Accessibility 6, Bilingual 8, SEO 7, Security 9, Tests 6.
No critical or high findings. The page set is solid: the 152 sitemap entries and hreflang pairs are correct, KA and EN carry identical test-id structure, there is no overflow at 375px, and the workbooks and RSC payload leak no internal metadata. The one clear design-rule gap is the births/deaths chart, which has no legend (colour-only meaning). The rest is duplicated helpers, some payload weight, and redundant tests.
Counts: critical 0, high 0, medium 3, low 12.

## Not checked (and why)
- Number correctness (out of scope).
- Real screen-reader behaviour (NVDA/VoiceOver) and an automated axe pass: no tool installed; only DOM roles, names and a 70-stop Tab run were inspected. Computed contrast was not measured.
- The index map's keyboard and touch behaviour and the `#lvl=region` tab beyond what the existing spec covers; only the 375px layout and DOM were reviewed.
- Chart render cost beyond node counts (747 DOM nodes on Imereti at 375px, 1,075 on the index); no CPU profile was taken.
- Georgia page `/en` workbooks and the other 74 place pages individually: the sample was Imereti, Lentekhi/Oni, Batumi, Tbilisi, Georgia and Kvemo Kartli. HTML size varies only with the member count.
- The `x-default` hreflang and sitemap `lastmod` semantics were checked for structure only (152 entries = 76 pages x 2 languages).
