# U03-expenditure — /explorer/expenditure (ka) and /en/explorer/expenditure

Reviewed against the live build at http://localhost:3100 on 2026-10-12. Method: curl, code reading, and throwaway Chromium scripts in /tmp/review-U03-expenditure/ (1440px and 375px, both languages, both groupings, chart and table, keyboard, Excel download). Playwright specs could not be run (see "Not checked").

## Summary
Scores (1-10): code quality 6, performance 6, UI/UX and design 8, mobile 8, accessibility 5, bilingual 8, SEO 9, security 9, tests 6.
The page is solid and clean on SEO, security, overflow and mobile layout: no console errors, no horizontal overflow at 375px, hash input is whitelisted, the Excel file leaks no internal ids. The weak points are accessibility (no skip link, chart has no text alternative, ministry carets share one name, data table lacks row headers) and payload/bundle waste (analysis code and the whole ministries corpus ship to a page that mostly does not use them).
Tests are broad but the explorer spec is bloated with duplicates and shell tests, and the Excel input builder has no unit test.
