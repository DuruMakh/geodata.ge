# U18-wages review (read-only)

Unit: `/explorer/wages` hub, `/overview`, `/industries`, `/regions`, `/regions/[id]`, ka and en. Live build http://localhost:3100.
Files read: `lib/pages/wages.tsx`, `components/wages/wages-explorer.tsx`, `lib/explorer/wagesWorkbook.ts`, `lib/explorer/wages.ts`, `lib/explorer/wagesRegionMap.ts`, `lib/explorer/wagesHubCards.ts`, `lib/i18n/messages/{ka,en}/wages.json`, `tests/explorer/wages.test.ts`, `tests/browser/wages.spec.ts`.

## Summary

Solid unit: SEO, security, bilingual parity and the Excel value column are correct. Main problems are payload size (Industries) and duplicated explorer logic.
Scores (1-10): code quality 6, performance 5, UI/UX and design 8, mobile 7, accessibility 6, bilingual 9, SEO 8, security 9, tests 7.
Counts: 0 critical, 0 high, 5 medium, 8 low.

Measurements.
- HTML (raw / gzip), ka: hub 86,432 / 13,808; overview 160,172 / 23,188; industries 646,567 / 42,850; regions 158,116 / 35,549; region/adjara 137,199 / 22,071.
- HTML (raw / gzip), en: industries 606,537 / 38,996; regions 127,576 / 32,998.
- JS per page: 14 chunks, 765,161 B raw / 233,220 B gzip. The set is identical for hub, overview, industries, regions and region pages. Reference: `/explorer` (budget hub) 670,394 / 203,785.
- 375px: no horizontal page overflow on overview, industries, regions, region/adjara (scrollWidth = 375). No console or page errors.
- Excel (downloaded and read with ExcelJS): the Data sheet value column (col 3) has `#,##0.0` (average) or `#,##0` (median-only). The Year and Series columns have no number format. Source hyperlinks are absolute `https://fiscal.ge/downloads/methodology/wages/files/...`. No internal metadata columns.
- Security: URL hash is whitelist-parsed in `lib/explorer/wages.ts:88-99`. Unknown tab and sel ids are dropped. No `dangerouslySetInnerHTML`. The one external link carries `rel="noreferrer"`. Unknown region slugs return 404 (`dynamicParams = false`). No file paths or `sourceCell`/`sourceSheet` in HTML.
- SEO: canonical and ka/en/x-default hreflang present on all ten fetched pages. All 16 bilingual pairs are in the sitemap. Dataset and Breadcrumb JSON-LD present except where noted in U18-wages-09.
