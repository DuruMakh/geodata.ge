# U21-trade-overview-partners: Trade Overview, Trading partners, Domestic exports

Reviewed live build http://localhost:3100 (ka and /en), code in apps/web, DESIGN.md, one run of the three trade browser specs (38 passed, 1.3 min) and the eight trade unit files (34 passed, 3.3 s).

## Summary
Scores (1-10): code quality 6, performance 5, UI/UX 6, mobile 5, accessibility 6, bilingual 7, SEO 8, security 9, tests 6.
Main problems: the 218-row country list is dumped into the page flow (about 7,000 px of scrolling before the ranking, on phones and on any laptop under about 1,420 px), selecting all countries on a phone adds a 5,100 px legend, and the partners page ships 1.05 MB of HTML (215 KB gzip). Search in the country picker misses common names ("Turkey" finds nothing in English).
Good: no overflow at 375 px on any of the six URLs, all tap targets are at least 24 px, focus rings are visible, canonical and hreflang pairs are correct, KA and EN render the same controls, no unsafe HTML or hash injection found, all 38 browser tests pass.

Measured numbers (curl, raw / gzip): partners ka 1,050,908 / 214,992, en 1,004,687 / 209,440; overview ka 173,615 / 27,033, en 136,628 / 22,674; domestic ka 354,703 / 85,915, en 317,744 / 80,712. JavaScript referenced by each page: 15 chunks, 794,529 B raw / 241,637 B gzip, identical to the Trade hub (794,529 / 241,637) and the Unemployment page (788,347 / 242,413), so the unit adds no JS of its own beyond the shared baseline.
