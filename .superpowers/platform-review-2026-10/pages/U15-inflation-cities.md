# U15-inflation-cities review

Pages: `/explorer/inflation/cities`, `/explorer/inflation/cities/[city]` (ka + `/en`). Spot-checked Tbilisi (representative), Telavi (smallest HTML), Zugdidi (late start), Georgia index (largest HTML, 192 KB). Production build at localhost:3100.

## Summary
Solid unit: static, 404s unknown slugs, canonical/hreflang/breadcrumb correct, no console errors, no overflow at 375px, hash input is parsed safely, Excel carries only public columns. Main real defect is mobile table mode on a city page (13 stacked text links push the table 1,085px down; the Categories page already fixed this with a select).
Scores (1-10): code quality 6, performance 6, UI/UX 7, mobile 6, accessibility 7, bilingual 9, SEO/metadata 8, security 10, tests 7.
Measured: HTML Tbilisi ka 182,281 B raw / 34,102 B gzip; Georgia ka 191,966 / 38,434; Tbilisi en 142,866 / 28,895. JS: 15 chunks, 878,376 B raw / 273,072 B gzip (identical set to the inflation hub and categories pages; /about is 596,065 / 184,589).

## Not checked (and why)
- Correctness of numbers (out of scope).
- Colour contrast of every token (read from DESIGN.md only; no automated contrast run).
- Real screen-reader behaviour of the combobox/listbox (no AT available); only roles/attributes and keyboard behaviour inspected.
- Sitemap `lastmod` differs between ka and en for the same page (e.g. batumi 2026-09-11 vs 2026-09-30); `lib/seo/sitemap.ts:254` makes it deliberate (max of original and reviewed date), so not reported.
- `/en` mobile table pickers beyond Zugdidi/Tbilisi 375px overflow and tap-target scan; the English picker uses the same components.
- Lighthouse-style render timing of the chart (no profiler run); chart SVG is 5.2 KB (desktop) + 4.2 KB (mobile) in the HTML, judged cheap.
