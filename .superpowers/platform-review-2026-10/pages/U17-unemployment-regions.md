# U17-unemployment-regions review

Pages: `/explorer/unemployment/regions` (map index), `/explorer/unemployment/regions/[id]` (11 slugs, ka + `/en`). Representative: imereti; smallest/largest checked: racha_lechkhumi_kvemo_svaneti (smallest, longest name) and tbilisi (largest). Reviewed against the live build on :3100, 375px and 1280px, ka and en.

## Summary
The unit is in good shape: no overflow at 375px, no console errors, hash input is whitelisted, JSON-LD/hreflang/canonical/sitemap are correct, picker and map are keyboard-usable, and the Excel has no internal columns. Weak points: the index inlines the whole comparison dataset for a view that reads 12 numbers, the line chart has only a generic accessible name, and long neighbour-region labels are cut off on phones.
Scores (1-10): code quality 6, performance 6, UI/UX 8, mobile 8, accessibility 7, bilingual 8, SEO/metadata 8, security 9, tests 7.
Counts: 0 critical, 0 high, 3 medium, 11 low.
