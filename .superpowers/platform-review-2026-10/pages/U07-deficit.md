# U07-deficit review: /explorer/deficit and /en/explorer/deficit

## Summary
Page is solid: no overflow at 375px, hash input is validated, no raw HTML or external links in the page, hreflang/canonical/JSON-LD/sitemap all correct, focus rings visible, Georgian and English structure identical. No critical or high findings; the real defects are a forecast year that is unmarked in the chart tooltip, a hand-copied hash-restore that ignores hash changes, and two shell-level keyboard problems (no skip link, chart values pointer-only).
Scores (1-10): code quality 6, performance 7, UI/UX 7, mobile 8, accessibility 5, bilingual 9, SEO 8, security 9, tests 7.
Measured: HTML 107,832 B raw / 18,406 B gzip (ka), 84,920 / 16,711 (en); 14 JS chunks 746,979 B raw / 229,671 B gzip (about 179 KB raw is deficit-specific, rest is framework/shell); CSS 14.7 KB gzip; RSC payload 41 KB of the HTML; facts shipped are 4.2 KB and carry only the fields the client reads. Tap targets at 375px: tabs 36px, pill 36px, range chips 38px, series row 33px, handles 32x44, all above WCAG 2.2's 24px and DESIGN §12's 30px floor.
