# U23-external-flows review

Pages: `/explorer/external/money-from-abroad` (representative), `/explorer/external/current-account`, `/explorer/external/foreign-investment`, ka and `/en`. Checked on the live build at http://localhost:3100 (Chromium at 375px and 1280px), the code in `lib/pages/external.tsx` and `components/external/*`, and the unit and browser tests for this unit.

## Summary
Overall the unit is solid. It has no security problems, ka and en have identical controls, hash parsing is whitelist-only, and the 375px layout has no overflow and no console errors. The two real defects are the 1.2 MB inline data payload on Money from abroad and a search field on the 5-row Current account list that DESIGN §7.7 says should be hidden.
Scores (1-10): code quality 6, performance 6, UI/UX 8, mobile 8, accessibility 7, bilingual 8, SEO 7, security 10, tests 7.
Counts: critical 0, high 0, medium 2, low 15.

Measurements (live build):

| page | HTML raw / gzip (ka) | HTML raw / gzip (en) | inline RSC data in HTML |
|---|---|---|---|
| money-from-abroad | 1,545,376 / 107,141 | 1,518,120 / 104,789 | 1,276,696 chars |
| foreign-investment | 367,114 / 48,878 | 340,094 / 46,954 | 248,147 chars |
| current-account | 170,289 / 27,503 | 143,861 / 25,411 | 76,895 chars |

- JS referenced by every page of the unit: 15 chunks, 770,580 B raw / 235,770 B gzip. 112,594 B of that is a `noModule` polyfill that modern browsers skip, so modern browsers load 657,986 B raw / 196,143 B gzip. The sum is the same for the three pages. Debt is 753,287 B and Unemployment 788,347 B, so the shared baseline is not specific to this unit. ExcelJS is imported on click only.
- Long tasks at 4x CPU throttle, summed during load: Money 1,047 ms, Foreign investment 967 ms, Current account 492 ms, Wages overview 769 ms.
- Fonts: the two Georgian variable fonts are preloaded. No images apart from the logo.

## Not checked (and why)
- Numerical correctness of the data: out of scope.
- English pages at 375px: only the ka pages were measured at 375px; ka and en were compared at 1280px for controls and headings (identical), and the English text was read.
- Real screen-reader behaviour, Lighthouse and Web Vitals: no tooling; accessibility was judged from the DOM (roles, names, tab order).
- Touch tooltips on the line chart: not exercised.
- The Excel files themselves: only the builder code and the unit test were read. The `exceljs` download browser tests were not run for Foreign investment and Current account.
- `data:` mode (Supabase mirror) and the build-time loaders in `lib/data/externalFlows`: out of scope for a page review.
- Full vitest and Playwright suites: not run, per the brief; only `moneyFromAbroadRender.test.tsx` and `money-from-abroad.spec.ts` were run.
