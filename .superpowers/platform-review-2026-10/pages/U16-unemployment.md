# U16-unemployment review (overview, gender, age; ka + en)

## Summary
The unit works well: all 51 unemployment browser tests and 70 unit tests pass, no console errors, no horizontal overflow at 375px, canonical/hreflang/sitemap/JSON-LD are correct, hash input is whitelisted, and heatmap contrast is at least 4.86:1. The weak spots are shared plumbing: the sidebar prefetches about 380KB of extra routes, the main line chart has a generic accessible name, and there is no skip link. Inside the unit, the main problems are a duplicated hash-state hook and an overview page that blanks on a bad `sel` link.
Scores (1-10): code quality 6, performance 6, UI/UX 8, mobile 8, accessibility 6, bilingual 8, SEO 8, security 9, tests 7.
Measured: HTML overview 295,050 B raw / 39,754 B gz (ka), 258,036 / 35,056 (en); gender 218,756 / 33,202; age 277,683 / 38,234. JS for the page: 15 chunks, 788,347 B raw / 242,413 B gz (identical on all three pages). RSC data script is 194KB of the overview HTML. DESIGN.md §27 allows the summary line under the H1, so it is not reported.
