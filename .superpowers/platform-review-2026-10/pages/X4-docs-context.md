# X4-docs-context — docs and agent context vs current reality

Reviewed at commit `9177f036` (main, trade services merged). Live build: http://localhost:3100 (580 sitemap URLs, 290 per locale).

## Summary

The docs were brought up to date on 2026-10-11 (audit-fixes Task 18), but the three hubs that merged afterwards (Money and banks, Energy and food, Trade services) only reached Project_Definition.md and parts of DESIGN.md. So llms.txt, AGENTS.md, both READMEs, DESIGN.md §2/§6.2/§6.7 and database-import.md still describe a smaller site. The worst case is llms.txt, which tells AI clients that "no datasets beyond those listed here" exist.
The CLAUDE.md test-loop numbers are 5× out of date: 1,403 browser tests now, not 281; 485 unit-test files, not about 150. The README sends contributors to `prisma:migrate`, which the import runbook forbids.
Scores: 1 llms.txt 4/10 · 2 Project_Definition §2 8/10 · 3 DESIGN.md 5/10 · 4 AGENTS/CLAUDE 5/10 · 5 docs/ 6/10 · 6 READMEs 4/10 · 7 methodology registry 9/10.
