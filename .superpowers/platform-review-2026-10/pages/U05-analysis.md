# U05-analysis — `/explorer/analysis` (ka) and `/en/explorer/analysis`

Reviewed against the live build at http://localhost:3100 on 2026-10-12 (Chromium 375px and 1440px, curl, code read, 13 existing browser tests + 35 unit tests run).

## Summary

The page works and is well tested for layout: no console errors, no horizontal overflow at 375px, SEO tags are complete and the sitemap lists both language versions. The two real weaknesses are weight (the single-year page ships the multi-year explorer's code and unused message namespaces, so JS is 700 KB raw / 207 KB gzip, and internal glossary notes reach the browser) and a few accessibility and phone-interaction gaps in the charts.
Scores (1-10): code quality 6, performance 5, UI/UX 8, mobile 7, accessibility 6, bilingual 9, SEO 8, security/leaks 7, tests 7.
Counts: critical 0, high 0, medium 4, low 11.

Measured numbers (ka page; en is within 1%):
- HTML: 323,551 B raw / 33,646 B gzip (en 289,491 / 31,794). Of the raw HTML, about 171 KB is the inline RSC data script.
- JS: 15 scripts, 699,914 B raw / 207,461 B gzip. Framework chunks (`10a9d85…` 228 KB and `1viiy53…` 156 KB) are the bulk; project code is in `2isbonm…` 32.6 KB, `3tcc8l7…` 42.3 KB, `3nbnx1w…` 67 KB.
- Fonts: 3 woff2, 154 KB (shared). Images: 2 small SVG logos.
- DOM: 957 nodes at 375px, 977 at 1440px. No console errors or warnings in either language.

## Not checked (and why)

- Whether any number is correct: out of scope by brief.
- Dark mode / theme toggle: not part of the design (DESIGN.md §17).
- Excel export: the analysis route has no Excel button and `tests/browser/bilingual-analysis.spec.ts:40` asserts that; DESIGN.md §9 lists none, so there is nothing to review.
- Lighthouse or real-device CPU timings and hydration cost: no profiler is available in this sandbox; only transferred bytes and DOM node counts were measured.
- Screen reader output with a real AT: only DOM roles, names and focus order were inspected.
- Chart colour-vision simulation: only contrast ratios were calculated (muted 5.5:1, faint 4.5:1 on paper pass; Sport/other swatches 3.7/3.2:1 against paper pass 3:1; radar rings 1.2:1 are decorative).
- Full-suite runs, `npm run check` and the build: forbidden by the brief.
