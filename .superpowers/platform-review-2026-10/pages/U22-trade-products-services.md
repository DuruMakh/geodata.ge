# U22-trade-products-services: `/explorer/trade/products`, `/explorer/trade/services` (ka + en)

Reviewed against the live build at http://localhost:3100 on 2026-10-12. Read-only; measurements came from curl, a throwaway Playwright script in `/tmp/review-U22-trade-products-services/` (375 and 1280 px, axe-core 4.x, CDP CPU throttle) and two existing spec files run once each.

## Summary
Products and Services work, are keyboard-operable, have no horizontal overflow at 375 px and carry correct canonical/hreflang/sitemap entries. The main costs are on Products: a 1.11 MB HTML payload (264 KB gzip, 94% of it inline JSON), hand-written Dataset JSON-LD that is poorer than the shared helper, and a Services paragraph under the H1 that DESIGN §17 forbids.
Scores (1-10): code quality 6, performance 5, UI/UX 7, mobile 7, accessibility 6, bilingual 8, SEO 7, security 9, tests 6.
Side effect to know about: running `tests/browser/trade-services.spec.ts` rewrites 12 tracked PNGs under `docs/superpowers/reviews/2026-10-11-trade-services/` (finding 15). I restored them with `git checkout` after my run, so the tree is clean.
