# Geostat consumer basket weights — 2026

Untouched Geostat basket-weight workbooks, covering 2012–2026. Unlike the CPI
vintages this file refreshes once a year, in January, so it lives in its own
tree named after the latest year it covers. English is canonical; the Georgian
file exists to prove identical values and carries Geostat's own group wording.
Both hold one sheet with a total row, 12 COICOP divisions and 41 subgroups.
`source-manifest.csv` records each file's download URL, date, byte count and
SHA-256; `npm run data:check-inflation` re-verifies them.
