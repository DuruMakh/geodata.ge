# Geostat detailed consumer price indices, August 2026 vintage

These four untouched XLSX downloads were retrieved from the [English](https://www.geostat.ge/en/modules/categories/293/consumer-price-detail-indices) and [Georgian](https://www.geostat.ge/ka/modules/categories/293/samomkhmareblo-fasebis-detaluri-indeksebi) Geostat detail-index pages on 2026-09-26. The manifest records each exact download URL, original byte count and SHA-256. The folder name is the latest month published in the workbooks, not the download date.

`mom` means previous month = 100; `yoy` means the same month of the previous year = 100. The files include old basket items and sheets back to 2011. Neither the original files nor the original values have been changed.
