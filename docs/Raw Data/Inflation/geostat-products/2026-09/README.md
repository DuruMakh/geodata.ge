# Geostat detailed consumer price indices, September 2026 vintage

These four untouched XLSX originals were retrieved from the [English](https://www.geostat.ge/en/modules/categories/26/cpi-inflation) and [Georgian](https://www.geostat.ge/ka/modules/categories/26/cpi-inflation) Geostat CPI pages on 2026-10-17. The September release and download Last-Modified dates are 2026-10-02. The manifest records each exact download URL, original byte count and SHA-256. The folder name is the latest month independently verified in all four workbooks, not the download date.

`mom` means previous month = 100; `yoy` means the same month of the previous year = 100. The files include old basket items and sheets back to 2011. Original bytes and values are unchanged. The prior August vintage remains recoverable in Git history.
