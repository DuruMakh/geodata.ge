# Geostat CPI — vintage 2026-09

Untouched Geostat consumer price index workbooks, retrieved on 2026-10-17, covering data through September 2026 (release: 2026-10-02). English files are canonical; Georgian files prove identical values. The national sheet and, in the `yoy`, `mom` and `avg12` files, the six city sheets are read by the existing preparation tools. `source-manifest.csv` records all twelve URLs, retrieval dates, sizes and SHA-256 hashes; copied bytes match the reviewed source package. `npm run data:check-inflation` re-verifies them.

All previously published national, category and city values and missingness are unchanged. Earlier vintage originals remain byte for byte in Git history; public download paths stay stable. Basket weights, inflation targets and individual-product originals are separate packages and are unchanged.
