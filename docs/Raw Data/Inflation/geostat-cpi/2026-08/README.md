# Geostat CPI — vintage 2026-08

Untouched Geostat consumer price index workbooks, downloaded on 2026-09-11, covering data through August 2026. English files are canonical; Georgian files exist to prove identical values. The national sheet (`Georgia` / `საქართველო`) and, in the `yoy`, `mom` and `avg12` files, the six city sheets are read. `source-manifest.csv` records each file's download URL, date, byte count and SHA-256; `npm run data:check-inflation` re-verifies them. Geostat media URLs change with every monthly upload, so each vintage keeps its own.
