## Architecture

### 1. Route identity remains separate from data identity

Create a dependency-free route registry consumed by pages, links, sitemap, tests, and `next.config.ts`. The route parameter becomes `slug`; the page resolves it back to a numeric code before looking up CSV/database data. `next.config.ts` emits 64 explicit permanent redirects, so numeric URLs never render duplicate pages and do not enter the sitemap.

### 2. Metadata and structured data share pure facts

Entity SEO helpers accept already-computed totals, rank, category/share, coverage and review date. They return metadata descriptions and Dataset JSON-LD without changing visible summaries. Adjara and Georgia use dedicated branches so the code cannot accidentally claim a consolidated Adjara functional share or omit the 69-unit country adjustment.

Dataset distribution rules:

- expenditure explorer -> stable national expenditure CSV;
- revenue explorer -> stable national revenue CSV;
- municipal index -> stable municipal expenditure CSV;
- municipality, region and Georgia entity pages -> no `distribution` because their Excel workbooks are client-generated and have no stable HTTP URL;
- analysis -> no separate Dataset node because it is an interactive view over the expenditure/revenue datasets, not a distinct downloadable dataset.

### 3. Semantic changes remain visually neutral

Heading tags, captions and the caret change semantics only. Breadcrumb/footer targets may gain a small hit-area expansion. Desktop geometry, copy, typography, controls, charts, map and table presentation remain unchanged.

### 4. Performance work is evidence-gated

The first payload change is a narrow client-transfer contract: route/server logic keeps provenance fields, while the `MainExplorer` client receives only fields it reads. Current RSC evidence shows 1,168 repeated `sourceId` fields and 852 repeated `officialInstitutionLabelKa` fields on expenditure; neither is read by the client view model. Remove those fields at the server/client boundary and remeasure.

Only if that measured change misses the 20% route target may implementation proceed to a separate lazy-static-chunk design. Do not improvise a public endpoint, hide crawlable content, or add a runtime database request.

- Unknown slugs return 404.

- At least one audited route reduces raw HTML by 20%; no audited route grows more than 5%; blocking JavaScript does not increase.

- Full repository checks, build, browser tests and diff checks pass with the production site URL set.
