# Internet and Technology Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the bilingual Internet and technology hub (`/explorer/internet` with `/homes`, `/homes/[id]` for Georgia and 11 regions, `/users`, `/online`, `/devices`, and `/methodology/internet`), serving about 1,055 reviewed Geostat survey percentages.

**Architecture:** Follows the Housing hub as built (PR #191, merge `033e4c05`; `git diff 033e4c05^1 033e4c05 --stat` lists every shared file it touched; Education, merge `a8ac0083`, is the latest hub to have touched the shared registries and browser counts). The parts are an immutable research package, a TypeScript prepare/check step writing one canonical CSV, a loader with CSV/DB parity, a private Prisma mirror table, models on the shared `topicSeries` and `unitList` helpers, and three thin client components (topic pages, homes map index, area pages) composed from the shared explorer shell.

**Tech Stack:** Next.js 16, strict TypeScript, Tailwind v4, Prisma 7 / Supabase, Vitest, Playwright, SheetJS (`xlsx`, already a dependency), Python 3 stdlib only (research package; every source is `.xlsx`), Node (independent verifier).

**Spec:** `docs/superpowers/specs/2026-10-20-internet-design.md` (approved by Duru on 2026-10-20, 09:37 Tbilisi).

**Branch:** `claude/internet-digital-hub-77c9b5`, from `origin/main` at `a8ac0083`; the spec is committed there.

## Global Constraints

- One value per survey year, 2016–2026 (2026 is published and served). Smartphone ownership 2019–2026. Five regions (Kvemo Kartli, Samtskhe-Javakheti, Guria, Mtskheta-Mtianeti, Racha-Lechkhumi and Kvemo Svaneti) from 2020; Imereti 2016–2019 includes Racha. Geostat's "Other regions" column and "15 years and older" column are never served.
- Under each page heading only the one-line `LatestValueLine`, which must fit one line at 375 px. Nothing under the chart except one source line.
- No tab rows and no measure switches anywhere (the map has none either). Rows under headings; every row visible from the start; no nesting, no prefixes in series names.
- Topic pages: the chart shows one heading at a time (the `unitList` rule with the heading as the group). Area pages: every row can be shown with every other.
- Defaults: `internet.used_3m.total` (Users), `internet.bought_online.total` (Online), `internet.own_mobile.total` (Devices), the area's `homes_internet` row (area pages). Defaults stay first, selectable and removable; selection unlimited; search never scopes the bulk action or the count.
- Group rows and ids, in order: Everyone `total`, Towns `urban`, Villages `rural`, Women `female`, Men `male`, `age_6_14`, `age_15_29`, `age_30_59`, `age_60_plus`. Headings on people aged 15+ (daily, bought online) have no `age_6_14`.
- Each group keeps one colour on every heading and page; Everyone and an area's own rows are ink; computer rows on area pages are dashed in their internet counterpart's colour; activity and public-services rows take the palette by position.
- Percentages to one decimal, rounded from the 15-significant-digit display value half-up (93.34998… → 93.3). Missing means a gap, a dash or a blank Excel cell, never zero. `…` and `x` produce no row.
- Fiscal.ge computes nothing. Every row has `unit = percent`, `basis = actual`, `value_status = survey_estimate`.
- Regions use the site's 11 region IDs (`HOUSING_REGIONS` / `BUSINESS_REGIONS`, in `REGIONAL_ECONOMY_REGIONS` order for the map). Stable lowercase ASCII IDs `internet.{measure}.{group}` (spec §8).
- The canonical CSV is UTF-8 with BOM. The methodology bundle must not pull large data files (PR #170 rule).
- No MCP tools, no central JSON/CSV publications; the fact-query snapshot must not include internet sources.
- Review before pushing: commit locally only. Screenshots, and on request a pushed-branch preview, go to Duru (Task 9). Full gates and the PR only after Duru's OK (Task 11). Times to Duru in Tbilisi time.

## Review Focus

2. **Area links carrying Towns or Villages** to a region page: Georgia's `homes_internet.urban,homes_computer.rural` moved to Guria becomes `homes_internet.region_guria,homes_computer.region_guria` (no duplicates), and Guria's rows moved to Georgia become `total`. Owner: Task 4 (`internetAreaSelectionHash`), Task 7 (browser).
3. **Early regional gaps**: Guria 2016–2019 is a dash in the table, not 0; Imereti has 2016–2019; the map uses 2026 with 11 regions; no "Other regions" row exists. Owner: Task 1 (`test_region_coverage`), Task 4, Task 7.
4. **Display rounding**: own mobile 2026 publishes `93.3`, homes with internet 2016 `70.1`, bought online 2026 `38.6`. Owner: Task 1 (`test_anchor_values`), Task 3.
5. **Names that repeat across headings** ("Towns" under three headings) carry their heading in the chart tooltip, table and Excel; a language switch keeps selection, range and mode on topic and area pages. Owner: Task 4 (`internetSeriesLabel`), Task 5, Task 7.
