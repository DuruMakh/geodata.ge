# Jobs by industry, hours, informal work and young people — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four national pages (Jobs by industry, Hours worked, Informal jobs, Young people not in work or study) to the existing Unemployment hub from six Geostat Labour Force Survey tables, with a parity-checked CSV, a Supabase mirror table, Excel, methodology and source archive.

**Architecture:** A new reviewed dataset `labour` mirrors Crime and justice file by file: a stdlib-Python research package transcribes the archived workbooks, a TypeScript prepare step re-reads every cell and writes `data/imports/labour-annual.csv`, a loader serves it in CSV or DB mode, and one thin `LabourExplorer` (modelled on `EducationExplorer`) renders each page on the shared explorer shell. The Unemployment hub appends four cards built from the new facts; the existing four Unemployment pages are untouched.

**Tech Stack:** Next.js 16 (static prerender), strict TypeScript, Tailwind v4, Prisma 7 / Supabase Postgres, SheetJS + fflate (already in the repo), Vitest, Playwright, Python 3 stdlib (research package only).

**Spec:** `docs/superpowers/specs/2026-10-20-labour-detail-design.md`

## Global Constraints

- Georgian paths: `/explorer/unemployment/industries`, `/explorer/unemployment/hours`, `/explorer/unemployment/informal`, `/explorer/unemployment/young-people`; English mirrors under `/en`.
- Only the page total is selected by default: `labour.jobs.all.total`, `labour.hours.all.total`, `labour.informal.total`, `labour.neet.age_15_24.total`.
- One `LatestValueLine` "{measure} · {year}: {value}" under the heading, one line at 375 px; nothing else under the heading. No tabs, no icon switches.
- Every row flat under a heading in `FlatSeriesPanel`, list searchable; outside the list a row is "{heading} — {row}" except under the `all` heading, where it is the row name alone.
- Units: `thousand_persons`, `hours`, `percent`; every value shown with one decimal.
- Missing = gap / dash / blank Excel cell, never zero. Geostat `...` and an empty cell in a row are unavailable. A published `0` stays zero.
- Yearly only; last year 2025. No map, no MCP tool, no JSON/CSV publication; source IDs start with `geostat_lfs_`.
- `value` = the workbook's stored number text exactly; `published_value` = rounded to 1 decimal from 15 significant digits (8.4499999999999993 → 8.5).
- `basis=actual`, `value_status=survey_estimate`, `last_reviewed_at=2026-10-20`.
- No new production dependency. Do not edit the existing `geostat-labour-force-annual` package or the existing Unemployment pages.
- Review before push: narrow tests while building; full `npm run check` / `npm run build` / `npm run test:browser` only after Duru's OK on screenshots or preview.

## Review Focus

1. **A selected row with no values at all** ("Men — Households as employers" on Hours, alone): the list shows a dash, the chart shows the empty-years callout, nothing throws. Test in Task 4.
2. **A hash from another page or with unknown ids** (`#sel=labour.jobs.all.total` opened on Hours, or `sel=foo`): falls back to the page default; an explicit `sel=` stays empty. Test in Task 4.
3. **Range kept while switching to rows that start later**: range 2017–2019 on Jobs, then tick only "Women — Construction" → range refits to 2020–2025, never an empty chart. Test in Task 4.
4. **Long Georgian latest lines** on a 375 px phone: each of the four lines fits on one line in ka and en. Test in Task 8.
5. **Zero vs unavailable**: "Not identified" 2018 is a published `0` (served, shows 0.0); "Men — Households" hours `...` is never served; Excel writes 0.0 for the first and a blank for the second. Tests in Tasks 2 and 4.
