# Crime and Justice Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the bilingual Crime and justice hub. It has five national pages and a methodology page, and serves about 1,270 reviewed Geostat counts, each also readable per 100,000 people.

- Hub: `/explorer/crime`.
- Pages: `/recorded`, `/convictions`, `/prisons`, `/victims` and `/road-accidents`.
- Methodology: `/methodology/crime`.

**Architecture:**
- **Data pipeline and pages** follow Health's national pages (PR #190, merge `82497835`). `git diff --stat 82497835^1 82497835` lists every shared file it touched; leave out the causes-of-death, area-page and map files, because this hub has none.
- **Per-100,000 view** follows Money and banks' share-of-GDP view (`moneyBanksViewFacts` in `lib/explorer/moneyBanks.ts`). Rates are calculated in the model from the served counts and Georgia's served 1 January population. They are marked `calculated` and never stored.
- **The parts:**
  - an immutable research package;
  - a TypeScript prepare/check step that writes one canonical CSV;
  - a loader with CSV/DB parity and a private Prisma mirror table;
  - the shared `topicSeries` model;
  - one client component for all five pages.

**Tech Stack:** Next.js 16, strict TypeScript, Tailwind v4, Prisma 7 / Supabase, Vitest, Playwright, Python 3 with `xlrd` 2.0.1 (research package only), Node with the repository's SheetJS `xlsx` (prepare step and independent verifier).

**Spec:** `docs/superpowers/specs/2026-10-16-crime-design.md`, including the "Amended while planning" note. Duru approved it on 2026-10-16 (the "Approve the written design" card, 20:38 Tbilisi).

**Branch:** `claude/crime-hub-r6s42h`, from `origin/main` at `82497835`. The spec is already committed there.

## Global Constraints

- **Yearly values only.**
  - Recorded crimes: 2015–2025.
  - Convictions, prisons and road accidents: 2001–2025.
  - Victims: 2007–2011 and 2015–2025.
  - No "I-II quarters, 2026" value is served.
- **Page text.** Under each heading there is only the one-line `LatestValueLine`, in the form "{measure} · {year}: {value}". Nothing sits under the chart except one `SourceNote` line.
- **No tab rows.** Every page has the same icon-only `SegmentedTabs` measure switch with `ControlTooltip` (DESIGN §7.2a). Its options are `count` (Lucide `Hash`, initial) and `per100k` (Lucide `Users`).
- **Defaults.** Only the page total is selected: `crime.recorded.total`, `crime.convicted.total`, `crime.prison.total`, `crime.victims.total` or `crime.road.accidents`. It stays first, selectable and removable. Selection is unlimited, and search never scopes the bulk action or the count.
- **Lists.** Each list is flat under headings (`FlatSeriesPanel` `heading`), with no carets or nesting. Series names have no prefixes.
- **One unit per chart.** On Road accidents, ticking a row of the other unit (accidents vs persons) replaces the selection. This is the Business rule, used through the shared `keepOneUnit` from `lib/explorer/unitList.ts` that the Housing plan moves out of Business (Task 4).
- **Missing values.** Missing means a gap, a dash or a blank Excel cell, never zero. Geostat's `…` and `...` cells produce no row. A published `0` is served.
- **Computed values.** The only calculation is the per-100,000 rate: count ÷ `demography.population_total` (`country.georgia`, 1 January of the same year) × 100,000, to one decimal. A year without population (2001–2003) has no rate. Nothing else is derived.
- **Counting changes.** These are drawn with `EditorialLineChart` `breaks` (a gap plus a dashed "new counting" rule) and `ExplorerTable` `breakYears` whenever a selected series is in the break's `appliesTo`:
  - `registration_2018` on all recorded-crime series;
  - `drunk_driving_coverage_2025` on `crime.road.accidents_drunk`;
  - in the per-100,000 view only, the existing demography `census_recalculation_2025` at 2025, on every series.
- **Stable IDs.** Lowercase ASCII `crime.{topic}.{item}` (Task 1 table). Labels are display data.
- **File rules.** The canonical CSV is UTF-8 with BOM. The methodology bundle must not pull large data files (the PR #170 rule), and the 8 MB Unified Report PDF is linked, not archived in the bundle.
- **Not exposed elsewhere.** No MCP tools and no central JSON/CSV publications. The fact-query snapshot must not include crime sources.
- **Review before pushing.** Commit locally only. Screenshots, and on request a pushed-branch preview, go to Duru in Task 9. Full gates and the PR come only after Duru's OK, in Task 11.
- **Times.** Times told to Duru are in Tbilisi time (UTC+4).

## Review Focus

1. **The 2017→2018 jump.** With All recorded crimes selected over 2015–2025, the chart shows a gap and a "new counting" rule at 2018, and the table marks 2018. The range 2019–2025 draws no rule. Owner: Task 4 (`buildCrimeModel(...).breaks`) and Task 7 (browser).
2. **Per 100,000 before 2004.** On Convictions in the per-100,000 view, 2001–2003 are dashes in the table and blank in Excel, not zeros. The range strip still offers 2001, and 2004 shows 9,071 ÷ 3,937,716 × 100,000 = 230.4. Owner: Task 4 and Task 5.
3. **The victims gap.** Ticking Women shows values for 2007–2011 and 2015–2025, and nothing (no zero, no line across) for 2012–2014. Owner: Task 4 (`test_victims_gap`) and Task 7.
4. **Prisoners by status before 2010.** "Awaiting trial" shows nothing for 2001–2009. Geostat's `...` cells make no rows, and no zero is written. Owner: Task 1 (`test_no_placeholder_rows`) and Task 4.
5. **A saved link across units or measures.**
   - On Road accidents, `#sel=crime.road.accidents,crime.road.killed` keeps only the first one's unit (`crime.road.accidents`).
   - `#tab=xyz` gives the count view.
   - `#tab=per100k&sel=` stays empty.
   Owner: Task 4.
