# Housing and Construction Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the bilingual Housing and construction hub (`/explorer/housing` with `/permits`, `/completed`, `/prices`, `/regions`, `/regions/[id]` for Georgia and 11 regions, and `/methodology/housing`), serving about 3,200 reviewed Geostat values.

**Architecture:** Follows the Business hub as built (PR #189, merge `1f152091`; `git diff 59f5bf2c 1f152091 --stat` lists every shared file it touched; Health, merge `82497835`, is the latest hub to have touched the browser page counts). The parts are an immutable research package, a TypeScript prepare/check step writing one canonical CSV, a loader with CSV/DB parity, a private Prisma mirror table, the shared `topicSeries` model plus unit-list helpers moved out of Business, and three thin client components (topic pages, Regions index, area pages) composed from the shared explorer shell.

**Tech Stack:** Next.js 16, strict TypeScript, Tailwind v4, Prisma 7 / Supabase, Vitest, Playwright, SheetJS (`xlsx`, already a dependency) for `.xls`, Python 3 with `xlrd` 2.0.x (research package only, not CI), Node (independent verifier).

**Spec:** `docs/superpowers/specs/2026-10-16-housing-design.md` (approved by Duru on 2026-10-16, 20:38 Tbilisi).

**Branch:** `claude/housing-hub-sgde9y`, from `origin/main` at `82497835`; the spec is committed there.

## Global Constraints

- Yearly values only. Permits and completed buildings run 2006–2025; Geostat's "2026 January–June" column and the quarterly workbooks are never served.
- Home prices: each year is Geostat's **fourth-quarter** cell, copied exactly; index 2020–2025, districts 2021–2025. A year without a published Q4 is not served. Nothing is averaged.
- Under each page heading, only the one-line `LatestValueLine`. Nothing under the chart except one `SourceNote` line.
- No tab rows and no measure switches anywhere (the Regions map has none either). Each unit's rows sit under a heading naming the unit; the chart shows one unit at a time; ticking a row of another unit replaces the selection (Business rule).
- Every row is visible from the start under its heading; no nesting, no collapsible parents, no prefixes in series names.
- Defaults: All buildings · Number (Permits, Completed); All homes index (Prices); Permits — all buildings · Number (area pages). Defaults stay first, selectable and removable; selection unlimited; search never scopes the bulk action or the count.
- Display: counts whole numbers; floor area stored in m², shown in thousand m² to one decimal in charts, tables and lists, million m² to one decimal (thousand below 1 million) in latest lines and hub cards; index one decimal; GEL per m² whole GEL.
- Missing means a gap, a dash or a blank Excel cell, never zero. `…` cells and absent columns produce no row.
- Fiscal.ge computes nothing. Every row has `value_status = official`, `basis = actual`.
- Regions use the site's 11 region IDs (as `BUSINESS_REGIONS`, in `REGIONAL_ECONOMY_REGIONS` order). Stable lowercase ASCII IDs `housing.{measure}.{group}` (spec §8).
- The canonical CSV is UTF-8 with BOM. The methodology bundle must not pull large data files (PR #170 rule).
- No MCP tools, no central JSON/CSV publications; the fact-query snapshot must not include housing sources.
- Review before pushing: commit locally only. Screenshots, and on request a pushed-branch preview, go to Duru (Task 9). Full gates and the PR only after Duru's OK (Task 11). Times to Duru in Tbilisi time.

## Review Focus

1. **Building-type columns that move or vanish between years** (the 2006 sheet's numbering row, "Administrati-ve", "restaurent"/"restourant", "Pre-school"/"Pre-schools", kindergartens missing in 2008 permits and several completed years, holiday camps only in 2022–2023 permits): each value lands on the right type, and an absent column is a gap. Owner: Task 1 (`test_type_columns_by_name`), Task 4 (model gap).
2. **A saved link mixing units** (`#sel=housing.permits_count.total,housing.permits_area.total`) keeps only the first row's unit; a price link with `sel=housing.price_index.total,housing.price_flat.district_vake` keeps the index only; years clamp to the unit's coverage (2021–2025 for districts). Owner: Task 4.
3. **Fourth quarter only:** no served price comes from a Q1–Q3 cell or from 2026, and 2020 Q4 reads 107.2 (not 100). Owner: Task 1 (`test_fourth_quarter_cells`), Task 2.
4. **Area-page link to another area** (picker or prev/next) carries the selection moved to that area, and a region without a value in an early year shows a gap. Owner: Task 4 (`housingAreaSelectionHash`), Task 7 (browser).
5. **Language switch** keeps selection, range and chart/table mode on topic and area pages. Owner: Task 7 (browser).
