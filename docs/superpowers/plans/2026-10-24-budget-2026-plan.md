# 2026 State Budget Plan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the 2026 state budget law's planned spending (by area and by ministry, basis `planned`) to the Spending pages, with the headline line showing the plan, marked.

**Architecture:** The law's Tavi III Article 9 (functional) and Tavi VI (appropriations) tables are read from `.docx` into the row shapes the 2025 actuals pipeline already uses, then run through the unchanged mapping, supplement, composition and admin-category code with `basis = planned`. Planned rows live in their own CSVs (`*-2026-planned.csv`) so the "2004-2025" files stay truthful; one combined loader per dataset feeds pages, validation, the DB import and publications.

**Tech Stack:** Next.js 16, strict TypeScript, Vitest, Playwright, `fflate` (already a dependency) for unzipping `.docx`, LibreOffice once (offline) to convert the two `.DOC` chapters.

**Spec:** `docs/superpowers/specs/2026-10-24-budget-2026-plan-design.md`

## Global Constraints

- Source: Law of Georgia on the 2026 State Budget, №1219-IVმს-XIმპ, adopted 10/12/2025, in force 01/01/2026, unamended as of 2026-10-24.
- Source id: `source.mof_2026_budget_law_planned`. Basis of every new row: `planned`.
- Reconciliation total: 30,881,358.0 thousand GEL (Tavi VI `00 00` "სულ ჯამი" 2026 column = Tavi I Article 2 payments). Functional part: Article 9 code `7` 2026 total. Supplements: financial assets growth 650,000.0 + liabilities decrease 2,919,761.0 thousand GEL. Tolerance 1,000 GEL.
- Existing 2004–2025 rows must be byte-identical after every task (`git diff` on existing CSVs shows nothing).
- Headline copy: en `2026 plan: Total 30.9 bn GEL +11.4%`, ka `2026 გეგმა: სულ 30.9 მლრდ ₾ +11.4%`; one line at 375 px in both languages (DESIGN.md §17). No other text under the heading.
- Out of scope: Revenue, Spending by type, Municipalities, Debt, Deficit.
- Do not push, open a PR, or run the full gates until Duru has seen screenshots and said yes (project rule). Commit locally.

## Review Focus

1. A 2026 row from the new `57 00` Civil Service Bureau must never land in an existing `57 xx` state-wide-payments series (e.g. `57 04` transfers to municipalities). Pinned in Task 4.
2. Share-of-GDP view with 2026 selected: 2026 has no GDP; the point must be absent (gap), not 0 or a crash. Pinned in Task 5.
3. Ministries view and Analysis view with only 2026 selected must render the plan mark and the "Planned budget data" label. Pinned in Task 5 (browser).
4. A program whose 2026 code changed but label did not must continue its 2025 series (no new one-point series beside the old one). Pinned in Task 4 by the concordance test.
5. When 2026 actual rows are later added, actual must win: `chooseActivePublicFacts` already does this; a regression test with a synthetic 2026 actual row pins it for the combined loader. Pinned in Task 2.
